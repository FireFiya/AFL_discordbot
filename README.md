# Discord 請假機器人

一個用於 Discord 伺服器的請假管理機器人。員工透過**按鈕面板**申請、查看、取消請假，管理員一次設置面板後即可長期使用。<br/>
此機器人是為解決discord內請假日期過難統整與管理而設計

## 功能特色

- 🏢 **持久按鈕面板** — 設置一次即可，機器人重啟後仍有效，員工全程用按鈕操作，不需打指令
- 📅 **請假申請** — 階層式選單（年 → 月 → 上/下半月 → 日），自動擋掉過去的日期，並防止重複請假
- 🔁 **定期請假** — 可設定「每周X」，自動排入當月所有該星期幾；每月 1 號自動續排下個月
- 📋 **月曆檢視** — 以圖片呈現當月每天的請假**人數**（不顯示姓名以保護隱私），可切換月份；下拉選單可查看某天「是誰」請假
- ✖️ **取消請假** — 員工可取消自己的請假，定期請假可整組取消
- 📢 **自動提醒**
  - 有人申請**當天**請假時，即時公開提醒大家
  - 有人取消**當天**請假時，公開提醒並更新今日請假人數
  - 每天早上（台灣時間 09:00）若今天有人請假，自動到面板頻道公告名單
  - 每月 1 號產生定期請假後，於頻道發一則總結（不 @ 任何人）
- 🗄️ **歷史封存** — 過期的請假不會被刪除，而是搬到封存檔保存，月曆可往回查看歷史
- 🏠 **多伺服器** — 可同時服務多個 Discord 伺服器，各自資料完全獨立、互不影響
- 🔑 **擁有者授權** — 只有機器人擁有者授權過的伺服器才能使用，防止被隨意加入濫用
- 🎛️ **狀態與開關** — 管理員可查看機器人狀態，並隨時暫停 / 恢復本伺服器的服務
- 🔔 **私訊通知訂閱** — 成員可訂閱，每天以私訊收到「今天誰請假」

## 指令

| 指令 | 說明 | 權限 |
|------|------|------|
| `!授權` | 授權目前伺服器使用機器人 | 僅機器人擁有者 |
| `!取消授權` | 取消目前伺服器的使用授權 | 僅機器人擁有者 |
| `!狀態` | 顯示機器人狀態，並可暫停/恢復（僅本人可見） | 需「管理伺服器」權限 |
| `!通知` | 開啟/關閉本伺服器的請假私訊通知（開/關切換，機器人私訊確認） | 任何成員 |
| `!設置面板` | 發送請假面板（詳見下方權限規則） | 依身分不同 |
| `!清空請假` | 清空目前（今天與未來）的請假記錄，歷史封存保留 | 需「管理伺服器」權限 |

### 🔔 私訊通知訂閱（`!通知`）

- 任何成員在伺服器內打 `!通知`，機器人會**私訊**確認「已開啟『伺服器名』的通知」；再打一次則關閉（開/關切換）。
- 訂閱後，以下三種通知除了在頻道公告，都會**額外私訊**每位訂閱者（標題會標明是哪個伺服器，可同時訂閱多個伺服器）：
  - **每日提醒**（早上）：今天有誰請假 / 無人請假
  - **臨時請假**：有人申請了當天的請假
  - **取消請假**：有人取消了當天的請假
- 若成員關閉了「允許來自伺服器成員的私訊」，機器人無法私訊，會在頻道提示他開啟後再試（訂閱不會生效）。

### 多伺服器與授權機制

- 機器人被加入新伺服器後**預設不運作**，需由**機器人擁有者**（綁定你的 Discord 帳號）在該伺服器執行 `!授權` 才會啟用。未授權的伺服器，面板按鈕與指令都會被擋下。
- 每個伺服器的資料（請假、封存、定期、設定）都存在各自的 `data/<伺服器ID>/` 資料夾，**完全獨立、互不影響**。
- `!狀態` 顯示一張卡片（伺服器名、運作狀態、面板頻道、請假/定期統計），下方按鈕可**暫停/恢復**本伺服器——暫停後面板與指令都會回覆「已暫停」，資料保留不動。

### `!設置面板` 的頻道白名單機制

為了避免面板被隨意張貼到其他頻道，採用「指定頻道」機制：

- **管理員**（具「管理伺服器」權限）執行 → 把**當前頻道設為指定頻道**（起頭或更改），並張貼面板。此指定頻道同時是每日提醒的發送地點。
- **一般成員**執行 →
  - 在**指定頻道**：✅ 正常張貼面板
  - 在**其他頻道**：❌ 被擋下（「只能在管理員指定的頻道設置面板」）
  - 管理員**尚未指定**過任何頻道：⚠️ 提示先請管理員設置

> 日常請假、查看、取消都透過面板上的按鈕完成，不需指令，也不需要任何權限。

## 安裝步驟

1. **安裝依賴**
```bash
pip install -r requirements.txt
```

2. **設定 Discord Token**
   - 在專案根目錄建立 `.env` 檔案
   - 新增以下內容：
```
DISCORD_TOKEN=你的discord_bot_token
```

3. **運行機器人**
```bash
python main.py
```

4. **授權伺服器**（每個要使用的伺服器做一次）
   - 由**機器人擁有者**在該伺服器輸入 `!授權`
   - 未授權的伺服器機器人不會運作

5. **設置面板**
   - 由具「管理伺服器」權限的成員，在想放面板的頻道輸入 `!設置面板`
   - 此頻道會成為指定頻道（面板與每日提醒的所在地）
   - 之後所有人即可用面板上的按鈕操作

## Discord Bot 設定

1. 造訪 [Discord Developer Portal](https://discord.com/developers/applications)
2. 建立新應用，並在 "Bot" 分頁建立 bot
3. 複製 Token 貼到 `.env` 檔案
4. 在 "Bot" 分頁開啟 **Message Content Intent**（讀取訊息內容，指令前綴需要）
5. 在 "OAuth2" > "URL Generator" 選擇權限：
   - `bot`
   - `Send Messages`
   - `Embed Links`
   - `Attach Files`（月曆圖片需要）
   - `Read Message History`
6. 使用生成的 URL 邀請 bot 加入你的伺服器

## 使用方法

設置面板後，面板上有三個按鈕：

- **📅 請假申請** — 開啟日曆，依序選擇年 → 月 → 上/下半月 → 日期送出
- **📋 查看請假** — 顯示當月月曆圖（每格為當天人數），可按 ◀ 上月 / 下月 ▶ 切換，並用下拉選單查看某天有誰請假
- **✖️ 取消請假** — 列出你自己的請假，選一個即可取消

以上互動畫面皆為**僅本人可見**（ephemeral），不會洗版。

### 🔁 定期請假（每周X）

在「請假申請」畫面，**上半月／下半月**旁邊有第三顆 **🔁 定時請假**：

1. 按下後，上方的年、月兩個選單會**合併成一個星期選單**（日～六），日期選單隱藏
2. 選擇星期幾 → 立刻把**本月今天起**所有該星期幾排入請假
3. 按 上半月／下半月 即可回到一般模式

**規則說明：**
- 定期請假一律套用**今天所在的月份**（定時模式下沒有年/月選單）
- 每月 **1 號 09:00** 自動排入下個月，並在頻道發總結訊息
- 可同時設定**多個**星期幾（例：每周一 ＋ 每周三）
- 產生的假就是一般請假紀錄，可單獨取消某一天當作例外
- 不影響已過去的日子，同一人也不會重複請到同一天

**停止定期請假：** 在「取消請假」選單中，🔁 每周X 會**置頂**顯示。選擇後**一律會停止定期**（下個月起不再自動排入），並詢問本月已請好的假要怎麼處理：

| 選項 | 效果 |
|------|------|
| **停止定期 ＋ 刪除當月假** | 連本月已請好的該星期幾一起清掉 |
| **停止定期 ＋ 保留當月假** | 本月已請的照常放，只是之後不再自動排入 |

> 刪除時**只會刪掉該星期幾**的假，你其他日子的請假完全不受影響，也不會動到別人的紀錄。
>
> 注意：若你曾**手動**請過同一個星期幾的假（例如先手動請了某個週一，之後才設定每周一），系統無法分辨來源，「刪除當月假」會將它一併刪除。

## 數據儲存

資料存放於 `data/` 資料夾，屬於機器人執行資料，請勿手動編輯。**每個伺服器一個子資料夾**，資料互相獨立：

| 路徑 | 用途 |
|------|------|
| `data/config.json` | 全域設定，儲存已授權的伺服器清單 |
| `data/<伺服器ID>/leaves.json` | 該伺服器現用請假（今天與未來） |
| `data/<伺服器ID>/leaves_archive.json` | 該伺服器歷史封存（每天凌晨自動搬入） |
| `data/<伺服器ID>/recurring.json` | 該伺服器定期請假規則 |
| `data/<伺服器ID>/subscribers.json` | 該伺服器訂閱私訊通知的成員清單 |
| `data/<伺服器ID>/config.json` | 該伺服器設定（面板頻道、啟用/暫停狀態） |

> 從舊版（單一伺服器、資料直接放在 `data/` 下）升級時，機器人會在啟動時**自動遷移**：把舊資料搬進面板頻道所屬伺服器的子資料夾，並自動授權該伺服器。

## 專案結構

```
AFL_discordbot/
├── main.py                  # 主程式
├── requirements.txt         # 依賴列表
├── .env                     # 環境變數（包含 Discord Token）
├── .env.example             # 環境變數示例
├── README.md                # 說明文檔
├── fonts/                   # 內附中文字型（月曆圖用）
└── data/
    ├── config.json          # 全域設定（授權清單）
    └── <伺服器ID>/          # 每個伺服器一個資料夾
        ├── leaves.json          # 現用請假資料
        ├── leaves_archive.json  # 歷史封存
        ├── recurring.json       # 定期請假規則
        ├── subscribers.json     # 私訊通知訂閱名單
        └── config.json          # 該伺服器設定（面板頻道、開關）
```

### 中文字型

月曆圖片需要中文字型。專案已內附 **Noto Sans CJK TC**（開源 OFL 授權，可自由散布）於 `fonts/` 資料夾，程式會**自動偵測**字型，順序為：

1. 專案 `fonts/` 內的任何 `.ttc` / `.otf` / `.ttf`（隨專案一起部署，跨平台最方便）
2. 常見 Linux 系統字型（`/usr/share/fonts/.../NotoSansCJK-Regular.ttc`）
3. Windows 微軟正黑體（`C:/Windows/Fonts/msjh.ttc`）

因此**部署到 Google Cloud 等 Linux 環境時，整包帶著 `fonts/` 即可，不需額外設定**。若想換字型，把字型檔放進 `fonts/` 即可自動採用。

> 註：微軟正黑體為專有字型，請勿放入公開 repo 散布；`fonts/` 內附的 Noto 字型才可自由散布。
